# Shader-kit

A collection of standalone shader projects, organized by effect.

## Shaders

- [3D Symbol Shader](shaders/3d-ascii/README.md) — a configurable three-pass GLSL 330 Core renderer with a 95-glyph visible printable ASCII library, shape-aware symbol matching, a raymarched demo scene, and Android-friendly WebGL 2 and desktop OpenGL previews.

## Live preview

[Open the 3D Symbol Lab on Android or desktop](https://dripxiecon.github.io/Shader-kit/web-preview/).

## Layout

Each shader lives in its own folder under `shaders/`, with its source files and a local README. Standalone tools and previews stay inside that shader's folder.
